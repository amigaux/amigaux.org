## amigaux 1.1.1

Released %DATE_1_1_1%, on [GitHub](https://github.com/amigaux/amix-media/releases/tag/1.1.1).
Tested in emulation only: the installer onto every controller 1.1 supports, on both lines (the
Z3660, the A4091, the A3000's and the A4000T's SCSI, and the A4000 and A1200 IDE port), and onto a
Buddha and a Catweasel Z-II; each ready-made image installed and booted on its machine and brought
up an X-Surf as `xsf0` by DHCP, two of them also with a fixed address. The new drivers are not yet
tested on real cards.

A point release of 1.1 with two new drivers, as packages. Both are tested in emulation only, on
both kernel lines, not yet on a real card. Everything else is as in [1.1](1.1.md).

### What is new in 1.1.1 {#whats-new}

- **Buddha IDE**, the module `buddha`: the two IDE ports of the Individual Computers Buddha. The
  system disk can be on either port, as master or slave, also a single drive jumpered as slave;
  CD-ROM drives work too. The machine boots from a Buddha disk through the card's own ROM, as
  before, and the kernel then drives it. Catweasel Z-II, its three ports: tested in emulation on
  both lines, the system disk on its first or third port, a data disk on the third and an ATAPI
  CD-ROM, with interrupt-driven I/O; not yet on a real card. Packages `buddha-k30` and `buddha-k46`.
  [The system disk](../hardware/index.md#system-disk).
- **X-Surf Ethernet**, the module `xsurf`: the Individual Computers X-Surf-100, in Zorro II or
  Zorro III, and the original X-Surf. The interface is `xsf0`, set up in `/etc/inet/interfaces`
  like any other, by DHCP or a fixed address. Packages `xsurf-k30` and `xsurf-k46`.
  [Networking](../docs/networking.md).

### Adding them to an installed 1.1 {#upgrade}

Both need kbootset 1.1.0.261114-45 or later. As root, first:

```
apkg update; apkg upgrade
```

Then the package for your kernel line, `-k46` on a 68040 or 68060, `-k30` on a 68030:

```
apkg install buddha-k46
apkg install xsurf-k46
```

The driver loads from the next boot. Without the upgrade the package installs, but kbootset
refuses to build a boot generation with it and says why; nothing changes.

A system disk moved to a Buddha from another controller needs one rebuild:
[moving the system disk](../hardware/index.md#moving-disk).

### The install media and images {#media}

The 1.1.1 files replace 1.1's: the same installer, which also installs onto a disk on a Buddha or
a Catweasel Z-II, and two new ready-made images for the master on a Buddha's first port
([on a Buddha](../install/ide-disk.md#buddha)). The install CD, the boot floppies and the Z3660
boot disk start 1.1's installer RAM disk unchanged, so three of its messages (two install discs in
the drives, a medium it cannot read, a disc that does not fit the machine) still say "amigaux 1.1
install disc"; that is expected, and it takes a 1.1.1 or a 1.1 install disc.

Every system installed from the 1.1.1 files carries both drivers in its boot generation: a Buddha
beside the system disk's controller is driven, and the first boot offers an X-Surf as `xsf0`, with
DHCP or a fixed address. A card fitted later comes up by DHCP when the system was set up with
DHCP, else by a line in `/etc/inet/interfaces`. [Downloads](../downloads/index.md).
