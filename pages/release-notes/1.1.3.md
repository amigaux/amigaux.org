## amigaux 1.1.3

Released %DATE_1_1_3%, as packages in the 1.1 repository (`http://pkg.amigaux.org/1.1`). There
are no new install media: a new install uses the [1.1.2 media](../downloads/index.md), then
`apkg`. An installed 1.1, 1.1.1 or 1.1.2 system takes 1.1.3 in place with `apkg`.

### Installing CDE {#cde}

As root, after `apkg update` ([packages](../packages/index.md)), three steps in this order:

```
apkg upgrade apkg
apkg upgrade
apkg install cde
```

1. `apkg upgrade apkg` first: an older `apkg`, such as the 0.3.11 of 1.1 and 1.1.1, cannot read
   the new dependency rules. Without this step, `apkg install cde` stops with `apkg: missing
   dependency: amix-base>=1.0-38 (needed by cde)`, and nothing changes.
2. `apkg upgrade` brings the newer 68040/68060 kernel, and takes an installed X11R6.3 to the shared
   6.3-15.s, with `amix-base` and `amixrt`. Without the new kernel booted, the CDE File Manager
   fails at login on 68040/68060 systems. On a 68040/68060 machine, and on a 68030 machine coming
   from 1.1.1, `apkg` ends with `power-cycle to boot it`: switch the machine off and on, before or
   after step 3.
3. `apkg install cde` adds `motif`, `cxxrt`, `regex`, `libjpeg` and `cde`.

CDE with its libraries takes about 45 MB more disk on a system that already has X, and about
77 MB on one without X.

### What is new in 1.1.3 {#whats-new}

- **CDE, the Common Desktop Environment**, `cde` 2.5.3-4.s, with the desktop Korn shell `dtksh`.
  [Installing CDE](#cde)
- **Shared libraries for X, Motif and CDE.** X11R6.3 (`x11r6.3` 6.3-15.s), Motif (`motif`
  2.3.8-3.s) and CDE are now built with shared libraries, on our patched C library runtime
  (`amixrt` 1.0-5). Only the shared versions ship. Measured on a 68030 and a 68LC060, each with
  64 MB: a CDE session uses about 3.5–4 MB less memory than the static build. In return, login
  takes about 5–6 s longer, and each program starts about 0.4–0.9 s slower.
- `x11contrib` 6.0-1.s, new in 1.1.3: new X clients, in the shared form; `apkg install
  x11contrib`.

### Updated {#updated}

- `apkg` 0.3.15: when an install or upgrade stops part-way, `apkg` now says the package is
  partially installed, and which command lays it again. Before, it wrongly said the installed
  version was untouched.
- `xztop` 1.1.1-3.s: an upgrade of `xztop`, in the shared form.
