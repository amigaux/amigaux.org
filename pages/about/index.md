## About

amigaux.org collects the hobby projects that bring Commodore's Amiga UNIX to newer Amiga hardware.
asokero, isoriano1968 and jusii got it going again; many more people have contributed since, as the
[GitHub](../github/index.md) page shows.

### Contact and community

The #AMIX channel of the Amiga.dev Discord, and the Amiga Unix section of the EAB forums.

### Support {#support}

Bugs, install problems, questions and ideas go to [%SUPPORT_REPO%](%SUPPORT_ISSUES%) on
GitHub: an issue for a bug or an install problem, a [discussion](%SUPPORT_DISCUSSIONS%)
for a question or an idea. Not sure where something belongs? Post it there and we pass it on. If you already
know which part is at fault, report it in that repository; the [GitHub](../github/index.md) page lists them.

Each kind of issue has its own form. A bug report asks for the machine, the accelerator and its
firmware, the kernel line (68030 or 68040/68060), the release file you installed from (as on
[Downloads](../downloads/index.md)), the steps that show the fault, and a copy of the console or
serial output. An install problem asks for the release file, how you started the install, the
controller and disk, and the step where it stopped. For a machine or card not yet supported, use
the [hardware support request](%SUPPORT_HARDWARE%).

Contact and rights questions go the same way, as an issue or a discussion. There is no e-mail
address for now.
